# mattkuna-media

**Public shelf only.** Finished images and videos for MattKuna social posts are placed here about 1 hour before they post, because Instagram and Facebook can only fetch files from a public address. Each file is removed again once the post is confirmed live.

- Nothing else lives here: no code, no plans, no settings, no secrets.
- The real files, and the "recipe" to rebuild every image and video, live in the private repo `Mattyz92/mattkuna` → `factory/`.
- Managed by the MattKuna content factory. Please don't edit by hand.

Folder layout: `live/<piece-id>/<file>` (empty between posts).
